# Persona Quest

A browser-based guided classroom game for teaching the relationship between **user personas, user needs, user stories and prioritisation**.

## Learning journey

1. Meet the client
2. Choose a user persona
3. Identify requirements supported by that persona
4. Build user stories using **As a / I want / so that**
5. Judge good and bad user stories
6. Prioritise the backlog
7. Review a scored summary

## Run locally

Open `index.html` in a browser. No server, installs, accounts or dependencies are required.

## GitHub Pages

This project is designed to run directly from GitHub Pages using the repository root on the `main` branch.

## Classroom use

Students can complete the activity independently and screenshot the final results screen as evidence of completion.
